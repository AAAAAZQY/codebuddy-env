## AI 编码硬约束（本工程）
基线：MISRA C + CERT C + 工程既有约定（原文 D:\AI Skill\ai行为约束.txt）。
- 禁 malloc/free 及任何动态内存
- 不得改动未明确指定的文件/函数/ISR/状态机/宏/函数签名/全局变量；不得新增库、头文件、编译配置、链接脚本、启动文件改动
- 不得加未要求的备用路径、兼容分支、防御性分支、抽象层、重试
- 不得隐式改安全关键逻辑与阈值（限位、堵转、过流、温度）或版本号/协议 ID/命令码/时序常数
- 不得关闭或弱化断言、看门狗、超时与安全检查；需求含糊必须先问；不得声称未验证的结论
- ISR 短小确定、无分配无阻塞无 printf 无浮点（除非 FPU 与时序已证）；共享数据用工程既有临界区并说明；DMA/缓存路径说明 barrier/clean/invalidate
- 控制环内 sin/cos/atan2 用 CORDIC 或查表；不擅自给电流采样/PWM 加平滑滤波；gimbal_task 强实时不得阻塞
- 工作方式：先复述需求与假设 → 证据定位（文件:行号、时序推理）→ 最小 diff 方案与影响 → 只改批准范围 → 验证后如实汇报（改了什么为什么、常量前后值、实时路径周期代价、风险与回滚）；一次一个逻辑改动，禁止重构混入；边界校验只放外部数据进入内部模型的唯一入口，多处重复修补要停下报告边界设计问题

## OLED 页寻址（SSD1306 兼容，128×64，I2C 0x78，本工程实测）
- 显存 8 页×128 列；1 字节=1 列竖排 8 像素（bit0 最上）。API 的 y=页号 0~7，竖直只能按 8px 对齐。
- 写入顺序：字节内竖 8 像素 → 同页内字节从左到右 → 一页写完才重新 SetPos 换下一页（跨 8px 图形必须逐页 SetPos，如 8×16 字符写 y 和 y+1 两页）。
- 字节下标=(像素行/8)*图标宽 + 像素列，bit=像素行%8；数组长度必须=宽×页数（28×4=112 B，42×4=168 B），否则 DrawBMP 读越界画花。
- 无帧缓冲，软 I2C 205kHz，整屏 1024 字节推算≈0.1s；只做分区局部刷新，重复整屏清屏会闪。
