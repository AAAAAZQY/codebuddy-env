## 2026-11-02 事故教训
副本里绝不能新建 .gitignore / .gitattributes / .git：
- 桥接会同步进真实工程并用受信进程写盘 → 被 DLP 加密（8192 对齐/%TSD-Header）
- .gitignore 加密后 git 读不了 → 规则静默失效
- .gitattributes（`* -text`）改掉仓库行为 → 122 文件被判"整文件重写"（63100 增/63027 删），VSCode 显示 250 更改，误以为代码被改
- 判据：`git check-attr text -- <file>` 返回 unset 即中招；`git ls-files --eol` 大量 i/lf + w/crlf 不匹配
- 修复：手动删真实工程里被同步的文件（删除不经桥接同步）；确要给真实工程加 .gitignore 只能用 PowerShell 直接在真实工程写（非受信 → 明文）
